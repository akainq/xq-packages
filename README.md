# The index of the XQ package registry

This branch is written by `tools/build.py` of the branch `main` of [https://github.com/akainq/xq-packages](https://github.com/akainq/xq-packages): do not change it by hand.
A file `<name>.toml` a package: its repository, and its versions — the commit of each, the XQ it is written for and
what it depends on. `xq` reads it to choose the versions of packages.
